# thilicapstone

The templates for **The Board Memo** — the capstone of *AI for Functions*. A team takes the practice files from the
four function labs, answers one question from a fictional board, and writes a two-page memo and a five-slide deck with
an AI assistant, without letting it change a number.

There is no code here and no data. The data is in the four lab packs. This folder holds the brief and the blank
templates.

> ⚠️ **A practice company, not a real business.** *Nila Foods* is invented. There are no answers in this folder.
> A real board memo draws on finance, HR and sales files that are confidential. Do not send real employee or
> distributor data to an AI service without approval from the people responsible for it.

## Get the data

The capstone uses the four lab packs, each in its own repository: `thilisupply`, `thilifinance`, `thilimarketing` and
`thilipeople`, all under <https://github.com/thili-ai>. Download each as a ZIP (green **`< > Code`** button, then
**Download ZIP**) and keep them side by side.

## What is here

| File | Used in | What it is |
|---|---|---|
| `board-brief.md` | Lesson 1 | The question as the board wrote it, with the eight offer products |
| `file-map.md` | Lessons 1, 2 | Which file in which pack holds what, and what one row is |
| `claim-ledger.md` | Lessons 3 to 5 | A table for every figure, where it came from, its status and its rating |
| `board-memo-template.md` | Lesson 5 | A two-page layout with seven sections |
| `panel-questions.md` | Lesson 5 | Questions a panel tends to ask, to practise on |
| `prompts.md` | All | Where the prompts are collected |
