# Claim ledger

One row per number or claim in the memo. **Status** is one of: **rebuilt** (you computed it yourself), **taken from AI**
(it came from a run you did not check), **assumed** (nobody computed it). Fix every row that is not "rebuilt":
rebuild it, mark it as an assumption in the memo, or delete it.

**Rating** is for a link in the story: **shown** (the files measure it), **consistent with** (the order and size fit,
and something else could explain them), or **not shown** (the files do not measure it, or point the other way). For any
link not shown, say what record would show it.
